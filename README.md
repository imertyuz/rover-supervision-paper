# Source-aware multi-sensor rover supervision: reproducibility evidence

This artifact accompanies the rover system paper. It documents the ROS 2–ArduPilot authority boundary, source-frame confirmation and timing analyses. It does not implement a new detector, local planner or certified safety controller.

## Run offline

Use Python 3.10 or newer and NumPy. No robot, ROS, GPU or network is needed after obtaining this package.

```bash
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
bash run_temporal_analyses.sh
```

The scripts load the unmodified frozen Fusion and Bridge functions with explicit ROS/service doubles and a virtual clock. They do NOT launch ROS or command a vehicle. Recorded FCU feedback is fixed; alternative confirmation after recorded HOLD is subject to open-loop censoring. Service acceptance is a simulation assumption, not a measured communication outcome.

## Contents and traceability

- Six frozen source files, SHA256 verified against field references.
- Reduced SQLite inputs for all four moving missions. Selected message blobs and nanosecond bag timestamps are preserved; new database files therefore have different file hashes. See export_provenance.json.
- Selected observer records, including original receipt times and FCU mode/arming.
- Fusion/Bridge conformance, full kappa histogram, rate–phase, matched-cohort/censoring and M=2/3/4 / windowed confirmation scripts.
- Reference result tables for temporal analyses, C3 characterization and stationary C1 supervision.
- Field request-message-receipt to first HOLD-state-receipt measurement script.

Training images, third-party datasets, C1 RGB images, model weights, full DataFlash and full mission bags are not included in this reduced artifact. C1/C3 reference summaries do not enable independent image annotation or re-integration of C3 raw motion: those are explicitly outside this artifact's reproduction coverage. No claim of a complete replica of the deployed ROS installation is made.

The original script relationships and legacy mission-window constants are retained. The histogram uses armed-AUTO windows; rate–phase analysis uses observer AUTO-to-WP5 windows. These cohorts must not be merged without accounting for their different selectors. Legacy rounded-stamp diagnostics are identified in the scripts; deployed source identity uses the frozen bridge logic.
